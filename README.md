# Calcifer

## About Calcifer

[![CodeFactor](https://www.codefactor.io/repository/github/alistarr/calcifer/badge)](https://www.codefactor.io/repository/github/alistarr/calcifer)

Calcifer is a private [Discord](discordapp.com) bot written in C# targeting .NET [9](https://dotnet.microsoft.com/en-us/download/dotnet/9.0) using the [Discord.Net](https://github.com/discord-net/Discord.Net) lib.


This bot is not really intended for use outside of the couple of servers I made it for. This is a tool for me to learn about the language and the lib.  The code is probably (read: is) sub par and should only be used as a very basic and shit example.

## Third Party Packages

- [dotenv.net](https://github.com/bolorundurowb/dotenv.net) 4.0.0 (.env file support)
- [Newtonsoft.Json](https://www.newtonsoft.com/json) 13.0.4
- [Camille](https://github.com/MingweiSamuel/Camille) 3.0.0 (Riot Games API C# Wrapper)
